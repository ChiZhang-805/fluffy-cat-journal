# Fluffy Cat · v15 可打断的多轮陪伴对话

基于已发布v14：修复回顾聊天的逐轮状态、流式回复、短句分页、失败恢复与上下文。
首页、六类记录、照片自动分析、日期补记、计时器、v14完整手写笔记、统计规则和猫咪原画保留。

## 这版怎样使用

完成记录进入相应板块回顾，或从已记录的首页卡片进入回顾。
长按底部按钮说话、松手提交。小猫尚未说完、正在淡出、思考或等待最终听写时，可以继续长按说新话。
旧请求和未展示的句子不再插话；图表一直保留在原位。

中文气泡至多16个可见字符（含标点），最多两行；长回复自然分句显示。
英文按词与实际宽度排版，不自动切回中文。点击气泡暂停/继续；文字聊聊仍可使用。
模型返回正文与气泡动作分开处理，不再因为缺少JSON数组或动作标签而丢掉正常回答。
用户原话在失败时保留，点气泡可显式重试；无可用结果时不编造答复。

会话只记入已经真正显示的助手短句，不把被打断的未展示后半段当成说过。
最近完整交流与更早有界摘录用于继续对话，不承诺无限历史记忆。
记录意图分析为独立辅助任务，失败不能替换成功的聊天，任何新增/修正都仍需用户确认。

## 服务分工与密钥

- **DeepSeek**：文字理解、回顾聊天、估时、翻译和记录意图。
- **浏览器听写**：用户主动长按后的语音转文字；音量用真实麦克风计算。
- **阿里云百炼**：食物和面部照片视觉分析，当前公开配置保持原项目北京地域与模型。

Key只保存在当前页面的私有客户端内存，不写入源码、URL、本地记录、日志或分享卡片。
GitHub Pages只托管静态页面；本原型由浏览器请求官方模型接口，依赖服务商CORS及网络策略。
正式多用户产品应把凭据、鉴权及模型请求迁到受控后端。

## 运行与测试

```sh
python -m http.server 8000
npm test
python tests/chat_v15_browser.py
python tools/build-standalone.py ../Fluffy-Cat-v15.html
python tests/chat_v15_standalone.py ../Fluffy-Cat-v15.html
```

页面本身不需要npm运行依赖；单元测试使用Node 20+，构建单文件使用Python标准库。
浏览器测试依赖见`tests/requirements.txt`，默认使用`/usr/bin/chromium`。
测试中的听写、API、权限和用户数据都是明确替身，不需要或索取真实Key，不运行付费请求。

详细状态机、重试边界、上下文策略、诊断与本轮验证见 **`docs/v15-recap-chat.md`**。
本轮：458项Node测试、172项浏览器/最终文件断言通过；96处命名函数/方法的输入、输出、功能注释通过。
真实麦克风、个人Key、iPhone/Safari和Windows更新工具尚未做端到端实测。
