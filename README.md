## 本版交互

| 部分 | 实现 |
| --- | --- |
| 首页 | 九个位置、六个卡片、三个空位。短点进入；长按拖动；空位移动、占位交换；网格外释放或取消回原位；下次打开恢复排列。长按不再弹卡片菜单。键盘 Alt＋方向键可替代拖动。 |
| 饮食 | 照片准备框在拍照/选择照片上方；照片完整等比显示。热量、蛋白质、碳水、脂肪全部全宽单列。去掉维生素及常驻长说明，营养仍标记估算。 |
| 面部 | 同样的照片准备框；保留用户自述和可见外观，不通过照片判断内心、真实疲劳或医学诊断。去掉旧常驻说明段落。 |
| 情绪 | 自由文字描述，无预设情绪选项，无强度或评分滑条；混合感受可以保留。语音用原始音频理解，不把音量大小当情绪分类器。 |
| 睡眠 | 两个24小时制时分框，日期自动补齐；醒来感受自由填写。23→07是前一日到记录日，01→07是同一天；夜间语境“11点到7点”按23→07处理。 |
| 备注排版 | 最后的多行描述框适度吸收空白，已有长表单保持合理最小高度，不强行拉长。 |
| 滚动 | 所有滚动条/滑块轨道隐藏，触摸、滚轮和键盘仍可滚动；无横向溢出。 |
| 专注 | 保留预计用时、AI估时、待办、暂停/休息/恢复/重置/完全停止；休息不累计专注；提前停止不会自动判定任务完成。 |

普通流程：**首页 → 填写／AI草稿 → 用户确认 → 小猫书写、放笔和等待 → 继续 → Great job! → 首页**。
专注流程先运行实际倒计时，结束或完全停止后才庆祝。

AI请求期间表单可编辑，主按钮暂时改为“停止整理”。小猫持续思考；取消、切页、换照片、清除Key都会阻止迟到结果覆盖当前内容。

## 两套极简 API 设置

手机外右上角分别为 **DeepSeek Chat** 和 **阿里云百炼**。下拉菜单只有名称、Key、启用、清除；异常时才显示短错误。
Key 保存在客户端实例私有内存，不写浏览器存储、录音历史或源码。启用校验只请求模型列表，**不意味着每一个模型都已经实测可用**。清除只清这套 Key，同时停止当前请求，不删用户字段。

公开配置在 `js/config.js`：

```javascript
bailianBaseURL: "https://dashscope.aliyuncs.com/compatible-mode/v1",
bailianVisionModel: "qwen3-vl-plus",
bailianAudioModel: "qwen3-omni-flash"
```

默认百炼为 **北京地域**。请使用对应地域、具有相应模型权限的 Key。其他地域可在公开配置修改官方端点及该地域可用模型；也支持官方工作空间专属端点。程序不会偷偷向多个地域试发密钥。

图像 → 百炼视觉模型；原始录音 → 百炼音频模型；文本整理／专注估时 → 既有 DeepSeek 路径（普通文本也允许已配置百炼）。没有百炼时，非情绪记录仍保留 DeepSeek＋浏览器转写的旧路径；情绪录音会要求百炼，避免把文字转写误称为语气分析。

照片只有点击“让小猫看看”才发送。音频只有主动长按录音、松手提交后才发送。首次麦克风许可仍是独立步骤，不把授权弹窗导致的松手/失焦当作取消授权。录音限90秒、单声道、16 kHz PCM16 WAV；输入轨道在松手时立即关闭，已收进处理器的末尾缓冲有界刷新，然后释放内存。

**静态网页直连依赖接口跨域策略、网络和Key权限。正式多用户产品应改为后端鉴权、短期令牌及受控转发，不能内嵌开发者共用长期Key。** 本项目没有假装部署了云后端。图像/声音发送给对应API服务，服务端保留策略由服务商和账号设置决定，不能用“本机未落盘”替代云端隐私承诺。

## 睡眠日期细节

默认以手机本地“记录日醒来”为锚点，按日历补齐，不通过 UTC 日期字符串推断“今天”。编辑历史记录使用该条历史日期。完整时间戳和本地日期继续存于记录数据，界面仅展示时分。

- 23:00—07:00 → 前一天23:00到记录日07:00，8小时。
- 01:00—07:00 → 同一天，6小时。
- “昨晚十一点半，今早七点一刻” → 23:30—07:15。
- “午睡，下午一点到两点” → 13:00—14:00，不套昨晚逻辑。
- 明确上午/下午、前天/昨天优先；多组时间要求用户核对，不选一组假装确定。
- 非法日期、零时长、超过24小时和夏令时不存在的时刻会校验；跨夏令时按实际经过时长计算。

旧记录的日期不丢失；旧情绪强度、旧维生素字段不再进入新表单、显示和导出。原始私有浏览器数据不被整库强行删除。

## 运行与测试

运行无需npm依赖：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

本地预览打包（图片、CSS和源码内嵌，无外部字体文件）：

```bash
python tools/build-standalone.py Fluffy-Cat-Journal-v5.html
```

自动化检查：

```bash
npm test
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
python tests/journal_v5_browser_test.py
python tests/media_v5_browser_test.py
python tests/refinement_test.py
```

可用 `CHROMIUM_BIN` 指定已安装的 Chromium；状态栏/动画旧回归脚本使用 `CHROMIUM_PATH`。
测试在内存文档运行真实源码；网络、存储、权限明确注入测试替身，音频采样测试使用人工正弦音源，**不是实际人的麦克风录音**。
完整验证范围见 `docs/v5-validation.md`；情绪研究与人工评测见 `docs/emotion-understanding.md`。

## 注释和模块

函数头说明输入、输出、功能；长函数按校验、主体处理和状态/资源回收等阶段组织。

```text
js/sleep-time.js        时分、日历跨天、口述时间和旧数据兼容
js/home-board.js        九槽布局、真实拖拽、交换/取消、存储迁移
js/bailian.js           官方端点白名单、私有Key、SSE解码、超时/取消
js/bailian-settings.js  第二套独立极简下拉设置
js/audio-session.js    原始PCM采样、真实音量、WAV、末尾刷新与资源释放
js/ai-journal.js        统一提示词、图像/音频调用、字段白名单、推断边界
js/catalog.js          唯一字段定义、校验、手写摘要
js/journal-store.js    历史兼容、记录/待办/布局存储，不存Key或录音
js/app.js              表单/媒体/模型/动画状态衔接与修改保护
css/refinement-v5.css   单列表单、相框比例、备注空间、隐藏滚动条
```

本次 **没有重新绘制猫咪，也没有修改核心动画图层**。状态栏仍沿用前版校准：时钟是真实设备时间，信号和电池是外观模拟，不是读取硬件信号/电量。尚未宣称与原生iPhone逐像素一致。
