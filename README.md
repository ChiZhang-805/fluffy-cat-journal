## 本轮界面

- **首页**：3×3坐标中右下角禁放，六个组件使用其他八个位置；长按拖动、交换、取消回位和布局保存保留。
  旧右下角的组件迁到合法空位，小猫气泡仍是原来的小气泡，不是九宫格卡片。
- **运动**：项目、时长、较高的备注三项。跑步/骑车距离及训练组次重量放进备注，旧记录距离不因删除字段丢失。
- **饮食**：空相框缩短、拍照按钮略矮，首次进入完整看到“吃了什么”输入框。营养字段仍单列，无维生素。
- **面部**：空相框略增高，初始完整看到自我感受但不露眼周的残标题；滚到底时从眼周开始，备注加高后贴合卡片。
- **睡眠**：一个主题化HH:mm—HH:mm时间区间、醒来感受、备注三项。选择器支持鼠标、触摸和键盘；保留跨夜与历史日期算法。
- **专注**：成功估时只填入分钟数，不显示黄色说明；不再显示“放入待办，稍后开始”。三项填写后直接开始。
- **对白**：圆体优先的设备字体回退，固定一行或均衡两行，不挤第三行，不把详细错误塞入气泡。未分发任何字体文件。

普通记录：**首页 → 输入／AI草稿 → 用户确认 → 小猫书写、放笔 → 继续 → Great job! → 首页**。
专注先运行倒计时；暂停/休息不累计专注，提前停止保留实际用时，不自动标记任务完成。
历史待办仍保留，删除的是新建专注表单里的“稍后开始”入口，不清空旧待办数据。

## 本地运行和单文件

原站点没有构建依赖，可用任意静态服务器：

```sh
python -m http.server 8000
```

独立预览构建：

```sh
python tools/build-standalone.py ../Fluffy-Cat-v6.html
```

预览内嵌实际图层、JS、CSS，不包含模型Key、测试替身、用户照片或私人记录。
手动流程可离线；语音和模型仍需要浏览器权限、联网和有效凭据，使用HTTPS部署更适合实际交互。

## AI与数据

保留已有DeepSeek和阿里云百炼两个外置极简设置菜单。Key只在当前页面内存，不随源码发布、不保存到记录或localStorage。
文字整理/专注估时走原DeepSeek路径；视觉和提交的原始音频走原百炼路径，配置仍在`js/config.js`，没有更换本轮模型。
录音/图片仍须主动提交，先生成可编辑草稿；取消或切页时阻止晚到结果覆盖用户输入。

默认百炼配置仍为北京地域。本文不声称已用用户Key验证模型；具体模型权限和音频/图片边界见现有v5文档。
情绪理解不输出强制分数或心理诊断，面部只处理自我感受与外观记录；营养内容仍是可修改估算。

记录保存在当前浏览器，不是跨设备云同步。浏览器清理、无痕模式或存储禁用会影响保留，界面会保留必要错误提示。
正式产品的Key鉴权仍应迁移到受控后端，本轮没有部署后端或云数据库。
