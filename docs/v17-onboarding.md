# v17 · 初见手记与现有 APP 衔接

## 界面改动

- 睡眠选项第一项是 `＜5 小时`，其余数值区间仍用短格式。英文字段使用 `<5 h` 等单行短语；语义键不变。
- 汇总页主标题是“从今天起，慢慢认识你。”，便签标题仍为“我的初见手记”。
- 汇总阅读区测量实际排版高度。常见的三项兴趣（两行）首屏截止在“运动”完整条目后；下一项“饮食偏好”不露出残字。更多选择/更长英文无法同时容纳六项时，窗口截止在前一个完整条目。所有条目的 padding 相同，不局部挤压兴趣或最后一项。
- 标题固定，条目有限滚动；向下能看见饮食偏好和落款，触摸/滚轮/键盘均可操作。没有滚动条，也不循环。
- 删除额外的 `complete` 页面。汇总是最后一页。显式点击“开启 NAVA 之旅”后进入原日记 APP。
- 原猫咪图层、信件逐笔轨迹、花饰、翻签和选项选择行为保留，不以截图切换替代交互。

## 首次使用、回访、旧用户

当前项目没有云端账户认证。“首次使用”指当前站点、当前浏览器的本地资料状态，不是跨设备的首次账号登录。

1. 新用户没有有效完成资料：展示欢迎页和七个问题。
2. 中途退出/刷新：恢复同浏览器里的草稿与安全的当前步骤，不标记完成。
3. 汇总点击完成：验证七项并写入一个独立资料对象，读回核对成功后才接入主应用。
4. 再次打开：读取有效完成资料，直接进入原应用。
5. 旧版本只有日记、没有初见资料：第一次展示引导，但不删除或改写已有记录、待办、计时和首页排列。
6. 旧的 `nava-first-notes-v3` 完整完成资料可兼容读取，不要求重复回答。
7. “我的”中增加“初见手记”，可以从汇总回看/修改选择，完成后仍进入原首页，没有新增结束页。

已有未完成专注计时继续按主应用的原恢复逻辑处理；接入引导不把计时重新归零。

## 存储与数据边界

完成资料键：`nava-first-notes-v3`（内部 schema version 4，兼容旧 version 3）。
途中草稿键：`nava-first-notes-draft-v1`。
共享主应用语言键：`fluffy-review-language-v1`。

资料仅含七项受控选项键、显示语言、完成/更新时间。没有 API Key、音频、照片、每日评分或自动生成的运动/睡眠记录。没有调用任何 AI，也不把性别、年龄等自动传入现有 AI 请求。问卷的“过敏或忌口”只是一个偏好选择，未收集具体过敏原，不能作为临床过敏资料。

禁用或写满本地存储时，汇总停留并由小猫简短提示；不创建假的完成标记、不直接跳首页。恢复存储后可以再次点击。清理浏览器站点数据/换浏览器会失去该完成标记。

## 宿主实现

- `onboarding.html` 是可交互子页面。它自带原素材，所有素材离线可解码，无第三方字体或资源请求。
- `first-notes-profile.js` 是两侧共用的字段白名单/完整性/草稿/保存校验。
- `first-run.js` 用受控 frame 隔离两套画布类和 CSS；主应用等待首次引导结束再初始化，避免出现两套同名全局变量、两个麦克风实例或重复绑定。
- 完成消息同时检查 `source`、`origin` 和随机频道；内容再次过白名单校验。
- 网页消息指定相同源；`file:` 单文件预览为不透明源，仅对已捕获 frame 使用 `*`，仍检查准确的 source 与随机频道。
- 在单文件构建中同一份 `onboarding.html` 内嵌为 srcdoc，不需要旁边放另一个 HTML。网页版使用同目录子页面。
- 汇总进入主应用前先保存，主应用素材就绪后淡入；清除已卸载 iframe，停止它的动画。主应用六入口、记录、书写、庆祝、回顾和双语均保留。
- 本次不修改服务器接口、模型、日记 schema、评分规则、头像素材或原有录音实现。

## 验证边界

537 项 node 单元测试：包含原有 521 项和本轮 16 项。
49 项针对最终单文件的浏览器检查：首次访问、未填阻止、完整汇总、有限滚动、回看修改、进入主首页、六类记录入口、实际手动运动保存与回顾、旧记录保留、中途恢复、英中文最大多选、手机宽度、保存失败/重试、消息来源校验、非减少动效翻页等。

浏览器因环境的导航限制，使用 `set_content` 加载实际交付单文件，显式隔离内存 localStorage；重开采用新文档及迁移后的测试存储，不宣称真实浏览器账户持久化已实测。测试不调用真人麦克风、摄像头或真实 AI，不包含用户 Key。iPhone/Safari、Windows 更新工具和线上实际部署仍需实机确认。
