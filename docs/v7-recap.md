## 体验与布局

普通流程：记录确认 → 连续书写/放笔 → Great job → 完成 → 对应类别的数据回顾。
专注流程：实际倒计时结束或主动停止 → Great job → 完成 → 专注回顾。
历史记录详情增加“查看回顾”，以该记录的日期和类别定位；不重复保存。

设计坐标393×852。顶部保留原系统时钟和安全区域。
回顾左上房屋返回首页，右上省略号展开菜单。中文菜单项均为图标加四字短语：
语言切换、分享卡片、评分依据、调整目标（运动/睡眠）、对话记录、文字聊聊。
菜单可盖住气泡；页面常驻内容没有免责声明段落、评分依据按钮或多余底部按钮。
日期下方是原猫图层实时渲染的趴睡角色；气泡仍为小型圆角对白，不是数据卡。
数值卡308–474，周视图488–710，聊天按钮744–808，底部保留安全距离。

点击周图的一天，只切换下方的小摘要；不另发模型请求、不改数据。

## 评分与事实分开

这是产品中公开、可追溯的回顾指标，不是经过临床验证的健康模型。
模型不自由产生数字分数；它读取计算结果与原记录，负责回应用户、解释和陪聊。
公式的解释只在“评分依据”菜单，主页面通过指标名称说明其含义。

| 类别 | 本版指标 | 计算 |
| --- | --- | --- |
| 运动 | 个人目标完成分 | 当天确认的运动分钟总和 / 个人每日目标 ×100，上限100；初始目标30分钟，可修改。 |
| 睡眠 | 时长目标匹配分 | max(0, 1−abs(当天最新记录小时−个人目标)/个人目标) ×100；初始目标8小时，可修改。不是睡眠阶段/质量评价。 |
| 专注 | 专注计划完成分 | 当天实际专注分钟总和 / 有实际计时的对应计划分钟总和 ×100，上限100；不计暂停与休息；不把提前停止当成任务完成。 |
| 饮食 | 饮食记录完整分 | 每份记录中餐次、食物、份量、热量、蛋白质、碳水、脂肪七项的填写比例，取当天平均。不是营养质量或越少吃越高分。 |
| 面部 | 外观记录完整分 | 自我感受、眼周观察、皮肤外观三项的填写比例，取当天平均。不是疲劳、健康、年龄或颜值评分。 |
| 情绪 | 原话与心情足迹 | 不生成情绪好坏分，保留当天最后一次确认的混合感受；周视图不画高低情绪曲线。 |

某天没有记录就是“—”，不补成0，不生成样例历史。热量和宏量营养仅汇总已填写的数据。
个人目标不是隐含的医学推荐，用户可在“调整目标”改动。改目标只重算展示，不改原记录。
用户的睡眠按记录/醒来日归类，其余按本地确认日期；日历跨月、跨年使用本地日期运算。

研究参考：Oura的睡眠分数使用总睡眠、效率、恢复、REM、深睡、潜伏期和时间等多种信号。
本项目没有那些传感器信号，所以不复刻或编造其健康评分；只借鉴“今日概览＋历史趋势＋可解释依据”的呈现方式。
来源：https://support.ouraring.com/hc/en-us/articles/360025445574-Sleep-Score （查阅2026-09-22）。

## 聊天不是第二次录入

底部“长按和小猫聊两句”保持一颗长绿色按钮。按住约420毫秒后启动。
首次权限未授予：解除本次按压 → 浏览器授权 → 回待机 → 再次长按才录音。
录音启动回调之后才显示倾听状态，文字/图标隐藏，按钮原位置展示实际麦克风音量历史。
最新音量在右侧，旧样本向左移动；静音只有低幅线，不随机伪造波形。
松手先停止收音，再提交；单次最长60秒，到限额自动停并提交。

- 百炼已启用：提交原始16kHz PCM16 WAV给配置的音频模型。
- 仅DeepSeek已启用：浏览器语音识别转写，然后文本交给DeepSeek。
- 不支持语音或不方便出声：菜单的“文字聊聊”仍使用同一个回顾上下文。
- 没有Key/失败/权限拒绝/没听到有效语音：如实提示，不用预置答案冒充成功。

当前使用**文字气泡回复**，没有接入声音合成。用户说话输入是真实音频链路，不是模拟。
有有效配置时，每份同日回顾首次打开会请求一次AI问候；无配置时显示本地短句模板。
模板不被标记为已经完成AI分析。

只发送：当前类别、当前回顾日及前6日的已确认数值和白名单字段、最近最多30条对应记录，
以及当前类别/日期会话最近六轮内容。没有其他类别、未确认草稿、原照片、Key或记录ID。
聊天API没有编辑记录/评分的工具。用户要求改记录时，引导去已有记录详情确认修改。
文本聊天的用户历史保留用户输入，不接受模型另造的转写。

密钥沿用原私有客户端；不会保存到localStorage、源码、分享图片。录音在提交后释放，不落盘。
对话仅存当前页面内存，按类别/日期隔离；刷新会丢失聊天，但不清空已保存的记录。
重复打开同一回顾不重复提交记录，点房屋、改Key、取消、隐藏网页会按状态清理媒体/网络。
请求带AbortController和会话代次，迟到回复不能切回页面或覆盖新一轮。

## 气泡与连续动作

模型返回JSON短句及soft/nod/wave/think四种白名单动作标签。
提示词要求接住感受、不机械播报数字、不空泛夸奖、不诊断、不以音量猜情绪，不把资料中的命令当系统指令。
提示词是约束与测试对象，不构成真实性或“温柔程度”的保证；需真实账号/语料持续评测。

每句按实际字体宽度切成一至两行，平衡两行宽度，保留内容而不是省略截掉。
单页展示3.3–6.8秒，随后约0.26秒淡出再显示下一句；最后一句留在原位。
点击气泡可暂停/继续；打开详情面板和切到后台时暂停阅读推进。菜单“对话记录”可补看消逝句子。
再次长按可中断上一段回复并开始下一轮。头部、嘴部、前爪与尾巴沿同一角色动画连续缓动，
轻微点头/举爪/思考不会换整张姿势图。原动画默认参数为0，不改变记录页体态。

## 语言、分享与权限

语言切换仅影响**本版回顾页界面及后续小猫回复**，不改动原记录页和用户原文。
中文菜单是四字短语；英文菜单使用相应简短英文。此版不是全APP双语改版。

分享完全在浏览器本地绘制PNG：包含所选类别的已确认回顾与图表，不包含对话记录/录音/Key。
先看预览，再选保存或系统分享。关闭面板后撤销临时URL；晚到图片不重新弹窗。
浏览器支持文件分享才出现系统分享按钮，点击时才调用navigator.share；否则保留保存图片。
来源：https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share （查阅2026-09-22）。

复用现有公开配置：`js/config.js`。模型参数、权限、地域和跨域策略由服务商决定，不自动把音频发给其他平台。
DeepSeek接口：https://api-docs.deepseek.com/api/create-chat-completion/
百炼音频：https://help.aliyun.com/zh/model-studio/qwen-omni
百炼文档区分音频/文字、多模态模型和stream输出；本版音频路径stream:true、modalities:["text"]。
默认已有北京地域配置未改动；不因为文档展示更近的型号就静默变更现有用户配置。
