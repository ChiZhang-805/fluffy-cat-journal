# v8：补记日期、记录页双语与六板块回顾

## 本轮范围

在 v7 基础上增量修改。猫咪的 PNG 图层、动画引擎、八个组件位置、长按语音、图片分析、表单布局和计时流程均沿用。新增代码没有真实模型 Key、录音、照片或个人手记。

六类记录页右上角均有三点菜单，中文条目为图标＋四字短语：**调整日期、语言切换、数据回顾**。记录菜单与回顾菜单分别管理，互不覆盖事件处理。

## 日期是记录的事情发生日

- 新记录默认打开表单时设备本地当天；日历支持今天及过去日期，不可选未来。日历与回顾的日期计算不用 UTC 解析 `YYYY-MM-DD`。
- 新增顶层 `recordDate`。`createdAt` 保留实际创建时刻；`updatedAt` 是实际写入时刻，不能为了补记伪造创建时间。
- 改日期只改变草稿元数据，保留字段和照片；日历中点击候选或浏览月份不提交，只有“确定日期”才生效。
- 各类别草稿日期相互独立。回到同类别恢复未提交日期，保存后清除该草稿日期，下次新建默认当天。
- 编辑旧记录保留 ID 和创建时间。更改日期会移动该条记录的日归属，不再保存第二份副本。
- 首页今日统计、陪伴天数、首页摘要排序、历史分组、近七天图表和对话上下文都使用事情发生日。今天补记上周，不算成今天已记录。
- 历史补记页面使用“那天/那晚”的标题，并在页眉显示选中日期。不增加额外占位区，不挤压输入框。
- 阅读旧记录时，依次使用已有顶层记录日、旧数据内记录日/睡眠醒来日、原创建时刻的设备本地日。读取不会改写持久存储。保存用户明确修改的记录才写入新的结构。

### 睡眠

选中的记录日默认是醒来日：`23:00—07:00` 计算为前日入睡、选定日醒来；`01:00—07:00` 在选定日内。改日期时清理此前推导的日期，再用相同的时分重新计算。语音明确提到另一个日期时，显示核对提示，不悄悄覆盖菜单选择。

### 专注

过去日期的专注是**补记已发生的专注**，因此按钮变成“补记专注”，时长标签为“专注时长”，不出现预计时长的 AI 估时入口。确认后保存自述分钟数，再进入庆祝与对应日期回顾，不把现在运行的计时器伪装成过去发生的行为。

自述记录保存 `focus.provenance = self-reported`，没有原计划时不生成计划完成分。当前日期的新任务仍进入原本的真实倒计时。

编辑已计时的旧专注时，表单展示实际用时，保留原 `plannedMs`。只改文字或日期不会改变原计时来源；明确修正实际时长后标记为自述。分数的分母仍是原计划，不使用被修改的实际时长充当原计划。

## 中英文

记录页/回顾页共用 `fluffy-review-language-v1` 的语言偏好。菜单、六类标题、字段名、单位、占位、照片操作、主按钮、日期、受控短气泡和主要验证提示支持中英。

界面就地更新，不重建表单，不改写用户值、不翻译用户原话。餐次仍存储原有兼容值，仅按钮显示翻译。照片宽高比、备注、日期、滚动位置和修改保护继续有效。

范围为本轮要求的记录与回顾页面，首页及“我的”等外围页面不是完整全站翻译。API 返回的原始错误消息可能来自服务商，不将所有未知字符串强行翻译。长篇用户内容保持原样。

## 首页气泡

气泡由 `top: 448px` 调整为 `top: 485px`（393 × 852 设计坐标），保留原来的浅色底、圆角、3px 左下圆角和文字，不变成组件卡、不铺满格子。右下角禁放组件规则不变。

## 回顾入口

六类都有两条路径：记录完成后进入对应板块回顾；记录页三点菜单直接查看该类别、选定日期的已保存数据。当前未确认草稿不会提前计入。零记录也有空回顾，缺失日不填假数据。

模型上下文包括所选日期、设备日期及 `historical` 标识；不能把过去的活动称为今天，不能把自述专注称为计时器测量。

## 代码组织

- `js/entry-menu.js`：三点菜单、日历、语言选择、键盘与焦点处理。
- `js/entry-i18n.js`：受控 UI 词典、标题、日期与简短对白。
- `css/entry-v8.css`：菜单日历与英语布局、小猫气泡位置。
- `js/journal-store.js`：事件日期、旧数据兼容、同 ID 编辑、日统计。
- `js/review-data.js`：按事件日期分组；专注来源与原计划；对话数据上下文。
- `js/app.js`：就地语言刷新、补记流程、语音/文本请求取消和草稿保留。

新函数头包含输入、输出、功能。复杂方法内部按阶段组织。不存在上传数据、照片或 Key 到 GitHub 的代码。

## 验证边界

测试证据在更新包 `verification/`。浏览器因环境策略拒绝 localhost 导航，因此测试用内存文档加载**同一份源码**，用隔离存储替身，不把它当成线上或真实设备检查。API 等待/媒体测试使用明确替身，无付费调用。重新打开测试使用新的浏览器页面，避免把同一页面重复注入脚本误当成真实刷新。

真实麦克风、摄像头、服务商 Key、iPhone/Safari，以及 Windows 已登录环境的更新脚本仍需用户环境验证。原始模型端点/权限逻辑未在本轮更换。

## 更新现有站点

外层 `Update-GitHub-Pages.cmd` 校验 GitHub 当前文件 SHA，提交白名单内增量文件，并检查线上 HTML、JS、CSS。不存在未知覆盖、force push、新建仓库或清空文件。

GitHub 连接本轮创建分支实际返回 403；交付包不代表线上已更新。工具在用户本机执行成功后才沿用原 Pages 地址发布。
