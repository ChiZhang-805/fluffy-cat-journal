# v6：表单比例、八位置首页与原样气泡

## 基线和交付

本轮基于 `ChiZhang-805/fluffy-cat-journal` 已部署的 v5 提交
`255d4c19c1d6f43be0bc903a07bdfb2044e182e5` 修改。版本标识为
`fluffy-journal-20260922-v6`。原画文件未变，未替换猫咪角色、手写轨迹或庆祝流程。
本轮 GitHub 集成创建功能分支返回 403，因此没有远程分支、提交或已上线的 v6 网站。
外层更新工具使用用户本机已授权的 GitHub CLI，读取清单保护基线，保留现有 Pages 地址与配置。

## 实现对应关系

| 需求 | 实现与验收方式 |
| --- | --- |
| 饮食首屏看见“吃了什么”整个框 | 空相框约94设计像素，拍照按钮38像素；FormLayout按实际字段/间距重新测量；食物输入框底部落在可见内容区内，下一项整体留在下面。 |
| 图片不能压扁或裁切 | 空状态才使用测量高度。上传后保留原始宽高比，横图和竖图分别测试；删除图片恢复空态。 |
| 专注不显示黄色估时依据 | 成功估时仅回填分钟数、短气泡；用户在请求期间修改的分钟数优先。必要的失败/输入问题通过已有toast提示，不冒充成功。 |
| 专注不再“放入待办，稍后开始” | 从进入专注的表单移除入口，三项填写后直接开始。已有历史待办/计时器不删除，旧数据不会被清空。 |
| 睡眠时间合并一行 | 一个“睡眠时间”外框内有四个可访问小时/分钟入口，两个标准HH:mm隐藏字段作为数据接口。奶油/浅青色菜单，24小时或60分钟列表，支持键盘、鼠标和触摸选择。 |
| 时间选择可取消 | 打开或导航候选不更改值；Enter或点选才提交，Escape/点外部/切页/失焦关闭。自动同步AI回填、错误状态与历史时分。 |
| 睡眠不滚动 | 时间区间、醒来感受、增高备注三块适配卡片。已收起选择器、无额外输入错误时整张表单不需要下滑；输入错误仍可见。 |
| 运动删除距离 | activity、durationMinutes、notes三项；备注容纳距离/组次/重量。语音/文本提示同步，不再要求不存在的距离；首页以时长显示。 |
| 旧运动记录保留 | sportData复制旧数据后合并距离，不直接改写原存储。已存在同值公里/米描述时不重复追加；读/编辑/确认/导出使用同一数据入口。 |
| 面部初始“眼周”不可露半截 | 空相框独立于饮食测量，约162像素；自己的感受完整显示，眼周整项位于视口外。 |
| 面部滚到底第一项是眼周 | 测量眼周、皮肤与备注组成的尾部高度，增高备注让尾部恰好占满可视内容区。不剪切字段、不依赖强制跳转滚动。 |
| 首页只有八个合法位置 | 保留九宫格坐标，索引8右下角禁放。旧布局该格内容迁到第一个合法空位，其余位置不动；拖放、交换、Alt+方向键、持久化共用规则。 |
| 气泡不是第九张卡片 | 沿用原圆角/浅色气泡，定位在空位范围内的猫咪右上方；不撑满格子，不遮脸，猫耳与气泡不相交。 |
| 字体和字数排版 | 采用设备圆体优先的CSS回退栈，不打包/分发字体。固定对白显式断成一行或平衡两行，通常每行5至6字，不靠字距两端拉伸。动态长错误完整放到toast，气泡保持短句。 |

## 关键文件

- `js/form-layout.js`：依据 ResizeObserver 读到的尺寸，测量空相框及面部备注高度。只在有效变化时写样式，避免观察回路。
- `js/time-range-picker.js`：组合时间控件。旧 `sleep-time.js` 仍负责日期、跨夜、语义时间和历史记录日期，不重复建立第二套日期算法。
- `js/bubble-copy.js`：全局受控短对白、别名迁移、安全textContent与详细错误分流。
- `css/refinement-v6.css`：只覆盖本轮布局；用户看到的猫素材及基线风格不重画。
- `js/catalog.js` / `js/ai-journal.js`：运动字段/旧距离迁移/模型schema统一。
- `js/home-board.js`：八合法位置和v2→v3本机布局迁移。
- `js/handwriting.js`：长备注适配时允许最小10设计像素笔画字号，避免60个汉字超出54像素书写区；不截断备注。

## 复现

```sh
npm test
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
npm run test:browser
python tools/audit-comments.py
python tools/build-standalone.py ../Fluffy-Cat-v6.html
python tests/standalone_v6_smoke.py ../Fluffy-Cat-v6.html
```

已安装其他Chromium时，可用`CHROMIUM_BIN`指定路径。测试的stdout与JSON记录分别保存；
不需要模型Key，也不产生付费API请求。真实运行使用静态HTTP服务器或既有HTTPS Pages站点。
