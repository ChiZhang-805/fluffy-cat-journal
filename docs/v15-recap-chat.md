# v15：可打断的回顾对话

## 修改范围

基于仓库 `8eb0e18d918dd43ae594f2a7d85ec7ae953f056e`（v14）实现。
只调整回顾聊天的传输、会话管理、短句显示及对应测试。记录字段、静态布局、统计规则、
原猫咪图层、v14循环书写到有限阅读、语音录入及百炼照片功能不改。

## 对话生命周期

```
待机 / 思考 / 正在说话 / 等待听写尾句
                 ↓ 达到420ms长按阈值
            停止旧轮 → 准备收音 → 实际倾听
                 ↓ 松手
             等待最终听写 → 请求DeepSeek
                 ↓ 收到完整短句
        排队显示（模型可继续生成）→ 自然结束
```

按下立即有轻微按压反馈；短按不丢掉当前回复。正式长按优先接受新发言，停止旧句和未显示队列。
`stop()` 用于本次松手后获取已识别尾句；`cancel()/abort()` 用于废弃旧轮。权限弹窗例外：
首次授权与真实收音仍然分开，授权期间不启用后台录音。

每一轮保存独立序号、会话键和AbortController。所有听写、网络、分页及辅助任务的回调都校验所属轮次。
即使取消后网络仍晚到、旧HTTP头在新轮后才返回，旧结果也不能显示。重复松手只会提交一轮。
取消、页面离开、语言/日期切换或Key变更，不作为“模型没回复”提示。

## 正文流与错误恢复

- `js/chat-stream.js`：实际消费DeepSeek SSE。支持UTF-8任意分块、CRLF、角色包、心跳、usage尾包、正常停止及DONE。
- 只取正文content，不读取reasoning_content、工具参数或私密响应体作为回复。
- `js/deepseek.js::streamText`：复用当前Key、模型和固定官方端点，强制非思考模式和流式正文，不设置JSON Output。
- `js/review-conversation.js`：保持只读回顾提示词，把字段整理的严格JSON契约与陪伴聊天分开。
- 旧式完整JSON回复仍有受控兼容：replies可以是字符串或带text的对象。没有gesture不再使正文失效。
  对象无法辨认时明确报格式错误，不从任意字段猜一段答案。
- 最多两次请求，共享60秒总时限；仅在尚无可用短句，且确认空正文或429/部分5xx时恢复一次。
  Retry-After过长不立即重发，取消会立即中止退避。未知网络状态、Key/权限故障、已收到部分内容不盲目重试。
- 流在中途断开：保留已完成短句，丢弃不完整尾部，随后用小猫气泡简短说明；不会从头重放。
- 完全失败：识别原话仍在内存，可点气泡显式重试；重试复用逻辑消息，不复制一条用户历史。
  再次长按可直接发起新话，不必先重试旧问题。
- 新增/修改记录意图是独立的可选任务。它失败不改变已经成功的聊天，也不自动写入记录。
  普通的感受澄清（例如“不是时间不够，是累”）不会仅凭否定句式被当作改记录请求。

## 气泡与小猫动作

中文每页至多16个可见字符（标点计入、换行不计），优先约14字，一页最多两行。
前端先按句意与词边界分页，再按实际字体宽度平衡换行；不强制缩小字号。
数值、单位、否定词、标点和英文单词有边界处理。极长单词按字符兜底，不丢内容。
英文按词和宽度排版，不套用16个英文字母限制。

网络增量先缓冲成完整句子/自然半句，不让一个字一个字的网络碎片频繁闪烁。
一页停留约2.5–4.2秒，现有260ms淡出仍保留。最后一页在下一句没到时保持可见；
请求仍在生成时可继续长按。点击气泡可以暂停/继续阅读。

轻点头、抬爪、晃手、思考等沿用既有角色的连续动作参数；本轮不会改变角色轮廓或换姿势图片。
图片、图表、回顾数据和底部按钮位置不变。

## 已说内容与未说内容

`js/chat-memory.js`维护每个“板块:日期”的独立账本：

1. 听写成功的用户原话在请求前进入内存，即使模型失败也不丢失。
2. 助手页面只有真正进入可见气泡后，才记入对话上下文；入队不等于展示。
3. 用户打断时，已显示页保留、未显示尾句丢弃，并标记interrupted。
4. 重试失败轮次复用其ID；模板提示、错误反馈不假装成模型成功回答。
5. 页面被隐藏或弹出遮挡层时暂停展示结算，不声称用户已看到队列里的内容。

最近六轮带完整/限长文本；更早的内容以有界原话摘录补充，不进行虚构总结。
每个会话保留最近40轮和最多8份早期摘录，最多18个板块日期会话。无界聊天入口不等于无限记忆：
超过范围的更早细节会被裁去，不能宣称永远记得全部历史。此版聊天依旧只在页面内存中，不跨设备同步。

## 无敏感内容的诊断

仅开发控制台显式运行：

```js
FluffyChatDiagnostics.snapshot();
FluffyChatDiagnostics.clear();
```

最多120个事件；只含临时数字轮次、事件名、相对毫秒、字符数、页数、尝试次数、HTTP状态和受控错误代码。
不含API Key、用户原话、模型回复、记录日期、照片、音频或请求地址，不自动上传。
这能区分听写空白、接口为空、截断、取消和辅助任务错误，不让所有失败看起来都一样。
